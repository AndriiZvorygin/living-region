# Import Schema

This document defines expected input files for `npm run import:region`.

Input root default is `know/input/`.

## Directory Layout

```text
know/input/
  gis/
    patches.geojson
    buildings.geojson
    networks.geojson
    stations.geojson
    freight-anchors.geojson
  calibration/
    road-maintenance.csv
    rail-maintenance.csv
    vehicle-costs.csv
    fuel-prices.csv
    building-energy.csv
    population.csv
    commodity-freight.csv
    land-use-transition.csv
```

All files are optional except `gis/patches.geojson`. Missing optional files produce info warnings.

## GeoJSON Layers

All layers must be `FeatureCollection`.

### `gis/patches.geojson`

Required fields:
- `id` (string; autogenerated if missing)
- `name` (default `Patch N`)
- `areaHa` (number; required for realism, defaults to `1`)
- `landUse` (default `mixed`)

Optional fields:
- `zoning`, `ownershipType`
- `nitrogen`, `phosphorus`, `potassium`, `carbon`, `moisture`

Notes:
- geometry may be null for import, but real GIS geometry is strongly recommended.
- unknown properties are preserved in `sourceProperties`.

### `gis/buildings.geojson`

Required fields:
- `id` (autogenerated if missing)
- `patchId` (defaults to first patch)
- `settlementId` (default `default`)
- `type` (default `dwelling`)

Optional fields:
- `dwellingUnits`, `occupiedUnits`, `floorAreaM2`, `condition`, `rentPerMonth`, `estimatedValue`
- `heatDemandKwhPerYear`, `insulationLevel`, `heatingSystem`, `retrofitLevel`

### `gis/networks.geojson`

Each feature represents one segment.

Required fields:
- `networkId` (or `id` fallback)
- `type` / `networkType`
- `lengthKm`

Optional fields:
- `condition`
- `capacityPassengerKmPerYear`, `capacityTonneKmPerYear`
- `maintenanceCostPerKmPerYear`, `maintenanceLabourDaysPerKmPerYear`, `maintenanceMaterialsKgPerKmPerYear`
- `capitalRenewalCostPerKm`, `bridgeOrCulvertFactor`, `winterMaintenanceFactor`, `climateStressFactor`
- `rightOfWayStatus`, `railElectrified`

### `gis/stations.geojson`

Station-like infrastructure. Typical types:
- `railStation`, `railHalt`, `freightSiding`, `intermodalDepot`, `marketDepot`

Key fields:
- `id`, `patchId`, `networkId`, `settlementId`, `type`
- `catchmentRadiusKm`, `walkCatchmentPeople`, `bicycleCatchmentPeople`, `parkAndRideCatchmentPeople`
- `freightCatchmentHa`, `passengerCapacityPerYear`, `freightCapacityTonnePerYear`
- `serviceFrequencyPerDay`, `condition`

### `gis/freight-anchors.geojson`

Freight-anchor infrastructure. Typical types:
- `grainDepot`, `coldStorageDepot`, `woodFuelDepot`, `farmInputDepot`, `repairMaterialsDepot`

Key fields:
- `id`, `patchId`, `networkId` or `stationId`, `settlementId`, `type`
- `commodityTypes` (pipe-separated string or array)
- `annualThroughputTonnes`, `railCapturePotential`, `roadCapturePotential`
- `storageCapacityTonnes`, `spoilageReduction`, `loadingEfficiency`
- `loadingLabourDaysPerTonne`, `anchorStrength`, `maintenanceCostPerYear`

## Calibration CSVs

CSV parser supports:
- header row
- quoted values
- commas inside quoted values
- blank lines
- comment lines starting with `#`

### `road-maintenance.csv`
Columns:
- `networkType`
- `maintenanceCostPerKmPerYear`
- `winterMaintenanceFactor`
- `bridgeOrCulvertFactor`
- `climateStressFactor`

### `rail-maintenance.csv`
Columns:
- `trackType`
- `maintenanceCostPerKmPerYear`
- `electrificationMaintenanceCostPerKmPerYear`
- `capitalRenewalCostPerKm`
- `railFixedCostAnnualOverride` (optional)

### `vehicle-costs.csv`
Columns:
- `vehicleType`
- `fixedCostAnnual`
- `fuelLitresPerKm`
- `electricityKwhPerKm`
- `maintenanceCostPerKm`
- `insuranceAnnual`
- `depreciationAnnual`

### `fuel-prices.csv`
Columns:
- `year`
- `gasolinePricePerLitre`
- `dieselPricePerLitre`
- `electricityPricePerKwh`

### `building-energy.csv`
Columns:
- `buildingType`
- `heatDemandKwhPerM2`
- `electricityKwhPerPerson`
- `retrofitCostPerM2` (optional)

### `population.csv`
Columns:
- `settlementId`
- `populationUrban`
- `populationRural`
- `households`
- `averageHouseholdSize`

### `commodity-freight.csv`
Columns:
- `commodity`
- `annualTonnes`
- `averageDistanceKm`
- `railSuitability`
- `perishability`
- `valuePerTonne`
- `essentiality`

### `land-use-transition.csv`
Columns:
- `fromLandUse`
- `toLandUse`
- `suitabilityMultiplier`
- `annualMaxHa`
- `labourDaysPerHa`
- `capitalCostPerHa` (optional)

## Units

Use consistent MVP units:
- area: hectares (`areaHa`)
- length: kilometres (`lengthKm`)
- money: dollars
- energy: kWh
- liquid fuel: litres
- freight: tonnes and tonne-km

## GIS Preparation Tips

1. Reproject/export to GeoJSON in WGS84 (EPSG:4326).
2. Precompute `areaHa` and `lengthKm` before export.
3. Add stable IDs to every feature.
4. Normalize `landUse` names to model categories.
5. Simplify geometry where needed for MVP performance.
