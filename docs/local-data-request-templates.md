# Local Data Request Templates

Use these short templates when requesting machine-readable local calibration data.

## 1. Food bank / meal program usage time series

Subject: Request for food program usage time series (CSV) for calibration research

Hello [Organization],

We are maintaining a public, evidence-audited regional resilience model and are seeking time-series food program usage data for [geography].

If available, could you share CSV rows with:
- geography
- organization_or_source
- indicator (`visits`, `unique_clients`, `households_served`, `meals_served`, `hamper_count`)
- period_start
- period_end
- value
- unit
- source citation/reference
- notes

We can attribute your source exactly as provided and keep caveats explicit.

Thank you,
[Name]
