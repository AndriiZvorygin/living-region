# Local Calibration Intake

This repository validates local calibration inputs through strict CSV contracts before using them in claim-readiness outputs.

## Input files

- `know/input/local-calibration/food-charity-series.csv`
- `know/input/local-calibration/food-price-series.csv`
- `know/input/local-calibration/rent-income-series.csv`

Schemas:

- `know/schema/local-calibration/food-charity-series.schema.json`
- `know/schema/local-calibration/food-price-series.schema.json`
- `know/schema/local-calibration/rent-income-series.schema.json`

## Required row fields

All intake rows must include:

- `geography`
- `indicator`
- `period_start`
- `period_end`
- `value` (numeric)
- `unit`
- `source_ref`
- `quality_tier`
- `notes`

Category-specific optional fields:

- food charity: `organization_or_source`
- food price: `basket_or_item`

## Source references

`source_ref` should map to a `source_id` in [know/source-manifest.json](/home/htaf/living-region/know/source-manifest.json).  
Missing `source_ref` fails validation. Unknown `source_ref` values are warned so intake can proceed while source manifests are being updated.

## Data class meanings

- `measured`: direct observed data rows from cited sources.
- `proxy`: transformed indicator with method/caveats.
- `manual_curated_input`: hand-curated input rows (must still cite source refs).
- `scenario_assumption` / `scenario_output`: assumption-driven model values, not forecasts.

## Validation behavior

- Invalid rows fail closed in `qa` and `rebuild:all`.
- Empty files are allowed and produce a summary with limitations.
- `quality_tier` must be one of: `direct_local`, `regional_proxy`, `provincial_proxy`, `national_proxy`, `scenario_only`, `unknown`.
- Food price aggregation across incompatible families (index/currency/percent) is blocked unless explicitly normalized in a derived stage.
- Unknown indicators are allowed with warnings.

## Derived outputs

Generated by `npm run report:local-calibration` and also run inside `qa`/`rebuild:all`:

- `know/produce/local-calibration-summary.json`
- `know/produce/local-calibration-summary.md`

## Calibration and claim readiness

Claim inventory includes:

- `calibration_status`: `calibrated | partially_calibrated | uncalibrated`
- `missing_calibration_refs`: explicit missing calibration rails per claim

This makes evidence gaps visible without changing headline conclusions unless real calibration data is loaded.
