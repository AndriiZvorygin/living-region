# Suitability and selection

The planner starts with Owen Sound / Grey County regional climate and a
selected site-capability scenario. It does not claim parcel-level soil
mapping. Each plant receives:

1. hard compatibility checks for winter survival, thermal-season requirements,
   water availability, user permissions and explicit regional exclusions;
2. continuous yield/suitability adjustments for soil depth, light, moisture
   and confidence;
3. inclusion and exclusion reasons suitable for the public contract;
4. an uncertainty penalty when evidence or parcel data is missing.

An override can include a candidate for an exploratory scenario. It is marked
as conditional and does not erase the underlying exclusion reason. Reference-
only species with unresolved yields remain visible but are not credited to the
canonical calorie system.

Named objectives are kept separate: low external input, low land, low labour,
nutritional completeness and resilience/diversity. The current selector
returns candidate rankings and named solution sets; it does not hide a set of
subjective weights in a single universal optimum.

Annual plots have sowing and harvest windows, rotation families and a finite
area. The scheduler reports conflicts rather than silently placing two
full-season crops on the same ground. Perennial layers share nominal area and
are bounded by canopy/root/light competition. Support plants are overlays with
explicit 15%, 25% and 33% sensitivities.
